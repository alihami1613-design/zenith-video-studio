# ZENITH Video Studio — MVP 0.2

## قابلیت‌ها
- ساخت پروژه برای مستند بلند یا ویدئوی کوتاه
- مدیریت ۷ مرحله تولید با تأیید انسانی
- تدوینگر مستند برای ترکیب کلیپ‌ها و صدا
- صفحه Auto Studio برای جست‌وجوی ویدئوهای افقی رایگان از Pexels، انتخاب دستی هر صحنه، تنظیم زمان صحنه‌ها بر اساس مدت صدای گوینده و خروجی MP4 با کیفیت 1080p

## راه‌اندازی Auto Studio
1. یک API Key رایگان از Pexels دریافت کن.
2. در تنظیمات برنامه Streamlit Cloud، بخش Secrets، این مقدار را اضافه کن:
   `PEXELS_API_KEY = "YOUR_API_KEY"`
3. برنامه را دوباره اجرا کن و از منوی صفحات، **ZENITH AUTO STUDIO** را باز کن.
4. سناریو را وارد کن و هر صحنه را با یک خط خالی جدا کن.
5. جست‌وجو را اجرا کن، ویدئوی هر صحنه را بازبینی و انتخاب کن، سپس خروجی را بساز.

اگر کلید را در Secrets ذخیره نکنی، می‌توانی آن را هنگام استفاده در کادر صفحه وارد کنی. کلید را در فایل‌های عمومی مخزن قرار نده.

## اجرای محلی در ویندوز
- Python 3.10 یا جدیدتر لازم است.
- در پوشه پروژه CMD را باز کن و دستورهای زیر را اجرا کن:

```bat
py -m venv .venv
.venv\\Scripts\\activate
py -m pip install -r requirements.txt
streamlit run app.py
```

## نکات و محدودیت‌ها
- صفحه Auto Studio به API Key رایگان Pexels و محدودیت نرخ درخواست‌های حساب Pexels وابسته است.
- جست‌وجوی خودکار ممکن است کلیپ کاملاً منطبق با مفهوم صحنه پیدا نکند؛ انتخاب هر صحنه باید توسط کاربر بازبینی شود.
- زمان صحنه‌ها با نسبت تعداد واژه‌های هر بخش به مدت فایل گویندگی تخمین زده می‌شود؛ این روش هم‌زمان‌سازی دقیق کلمه‌به‌کلمه نیست.
- خروجی افقی 1920×1080، 30fps و H.264 است.
- رندر در سرور Streamlit انجام می‌شود و به GPU رایانه کاربر وابسته نیست.
- هیچ سرویس پولی بدون تنظیم کلید و تأیید کاربر فراخوانی نمی‌شود.
