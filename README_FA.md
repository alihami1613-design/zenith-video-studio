# ZENITH Video Studio — MVP 0.1

## این نسخه چه کاری انجام می‌دهد؟
- ساخت پروژه برای مستند بلند یا ویدئوی کوتاه
- ثبت کانال، زبان و ایده اولیه
- مدیریت ۷ مرحله تولید
- ذخیره یادداشت‌ها و خروجی هر مرحله
- جلوگیری از تأیید مرحله بعد تا وقتی مرحله قبلی تأیید نشده باشد
- ذخیره پروژه‌ها روی همان کامپیوتر و خروجی گرفتن از پرونده JSON

## پیش‌نیاز
- Python 3.10 یا جدیدتر
- اتصال اینترنت برای نصب اولیه کتابخانه Streamlit

## اجرا در ویندوز
1. فایل ZIP را از حالت فشرده خارج کن.
2. داخل پوشه پروژه، در نوار آدرس File Explorer بنویس `cmd` و Enter بزن.
3. این دستورها را به ترتیب اجرا کن:

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
streamlit run app.py
```

4. صفحه برنامه در مرورگر باز می‌شود. اگر باز نشد، آدرس نمایش‌داده‌شده در پنجره CMD را کپی کن.

## نکته مهم
این نسخه، پایه مدیریت پروژه و تأییدهاست؛ هنوز خودش به سرویس‌های هوش مصنوعی وصل نمی‌شود و ویدئوی نهایی تولید نمی‌کند.
اتصال مدل زبانی، تحقیق وب، تولید تصویر/ویدئو، TTS و موتور تدوین در فازهای بعدی انجام می‌شود.
برای جلوگیری از هزینه ناخواسته، هیچ سرویس پولی بدون تنظیم کلید و تأیید کاربر فراخوانی نمی‌شود.
