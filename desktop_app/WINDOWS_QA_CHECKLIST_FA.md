# چک‌لیست آزمایش واقعی ZENITH Desktop روی Windows 11

این چک‌لیست برای اولین آزمایش روی رایانه کاربر است. آزمون‌های GitHub Actions قبلی، جای این آزمایش واقعی را نمی‌گیرند.

## فایل نصب
- از اجرای موفق GitHub Actions با عنوان `Verify installer preserves per-user recovery data on uninstall`، بخش **Artifacts** را باز کنید.
- فایل `zenith-desktop-windows-installer` را دانلود و ZIP را استخراج کنید.
- فایل `ZENITH-Desktop-Setup.exe` را اجرا کنید. نسخه فعلی امضای دیجیتال ندارد؛ هشدار SmartScreen در این مرحله ممکن است نمایش داده شود. فقط اگر فایل را از Artifact همین مخزن و اجرای موفق دریافت کرده‌اید ادامه دهید.

## آزمون نصب و شروع
- [ ] نصب در مسیر پیش‌فرض `C:\Program Files\ZENITH Desktop` کامل شد.
- [ ] برنامه از پایان نصب یا میانبر Start باز شد.
- [ ] پنجره اصلی بدون خطا نمایش داده شد.
- [ ] برنامه را ببندید و یک‌بار دیگر از میانبر Start اجرا کنید.

## آزمون پروژه و رسانه
- [ ] یک پروژه آزمایشی جدید بسازید و آن را در پوشه‌ای جدا از فایل‌های اصلی ذخیره کنید.
- [ ] یک MP4 کوتاه، یک فایل MP3 یا WAV و یک تصویر PNG/JPG وارد کنید.
- [ ] رسانه‌ها را روی ترک‌های جداگانه تایم‌لاین قرار دهید.
- [ ] پخش، مکث، جابه‌جایی Playhead و seek را امتحان کنید.
- [ ] یک کلیپ را جابه‌جا و کوتاه کنید؛ Undo و Redo را آزمایش کنید.
- [ ] یک تغییر ساده مثل Transform یا Color Grade اعمال کنید.
- [ ] پروژه را ذخیره کنید، برنامه را ببندید و پروژه را دوباره باز کنید؛ جای کلیپ‌ها و تنظیمات باید حفظ شده باشد.

## آزمون خروجی
- [ ] خروجی آزمایشی MP4 با H.264 و وضوح 1080p بگیرید.
- [ ] پیشرفت رندر نمایش داده شد و رابط کاربری پاسخ‌گو ماند.
- [ ] فایل خروجی در یک پخش‌کننده مستقل باز شد.
- [ ] تصویر و صدا پخش شدند و هم‌زمانی آن‌ها قابل قبول بود.
- [ ] در صورت امکان، یک رندر کوتاه دیگر را لغو کنید و مطمئن شوید فایل خروجی قبلی خراب یا حذف نشده است.

## ثبت نتیجه
اگر موردی شکست خورد، متن دقیق خطا و تصویر صفحه را نگه دارید. برای گزارش، نسخه ویندوز، نام/پسوند رسانه، مرحله‌ای که خطا رخ داد و اینکه پروژه ذخیره شده بود یا نه را یادداشت کنید. فایل‌های اصلی را برای آزمایش جابه‌جا یا حذف نکنید.

## حذف برنامه
حذف برنامه را فقط پس از پایان آزمون و نگه‌داشتن پروژه آزمایشی انجام دهید. آزمون CI قبلاً بررسی کرده است که پوشه نصب حذف شود و فایل آزمایشی بازیابی در `%LOCALAPPDATA%\ZENITH\Recovery` باقی بماند؛ در رایانه کاربر نیازی نیست فایل بازیابی واقعی را دست‌کاری کنید.
