# ZENITH Desktop — پایه نسخه ویندوز

این پوشه آغاز نسخه دسکتاپ مستقل ZENITH است. نسخه آنلاین فعلی حذف یا جایگزین نشده و تمام تغییرات این مسیر در شاخه مستقل `desktop-editor-foundation` انجام می‌شود.

## قابلیت‌های فعلی این مرحله
- رابط دسکتاپ PySide6 با ظاهر مشکی و طلایی
- ورود فایل‌های ویدیویی، صوتی و تصویری
- خواندن پس‌زمینه مشخصات رسانه بدون Decode فریم‌ها؛ مدت، ابعاد، نرخ فریم و وجود جریان صدا/تصویر
- نمایش مشخصات خوانده‌شده در فهرست رسانه‌ها و افزودن کلیپ با طول واقعی به تایم‌لاین
- ساخت Proxy سبک در پس‌زمینه با FFmpeg؛ نسخه پیش‌نمایش MP4 با عرض حداکثر ۹۶۰ پیکسل، کدگذاری کم‌فشار و حداکثر دو رشته پردازشی CPU
- ذخیره Proxy در Cache جداگانه کاربر؛ فایل اصلی هرگز جایگزین یا بازنویسی نمی‌شود
- استفاده خودکار از Proxy آماده برای پیش‌نمایش رسانه و کلیپ تایم‌لاین؛ مسیر اصلی در پروژه حفظ می‌شود
- استخراج شکل موج صوتی به‌صورت خودکار در پس‌زمینه برای رسانه‌های دارای صدا؛ نمایش دامنه صدا روی کلیپ‌های صوتی تایم‌لاین
- نمونه‌برداری سبک تک‌کاناله ۱۰۰Hz و تبدیل به ۲۰ ستون دامنه در ثانیه؛ Cache باینری فشرده و مستقل از فایل اصلی
- پیش‌نمایش رسانه با QMediaPlayer و QVideoWidget، همراه کنترل پخش و جست‌وجو
- مدل مستقل تایم‌لاین با زمان‌بندی صحیح بر اساس فریم
- نمایش گرافیکی ۸ ترک: V1 تا V4 و A1 تا A4
- خط‌کش زمانی، نشانگر پخش، بزرگ‌نمایی و اسکرول افقی
- انتخاب و جابه‌جایی کلیپ‌ها با ماوس در تایم‌لاین
- کوتاه‌کردن ابتدا و انتهای کلیپ با دستگیره‌های لبه؛ برش غیرمخرب و حفظ زمان منبع
- Snap مغناطیسی لبه‌ها به ابتدا/انتهای کلیپ‌های دیگر و مکان‌نما
- Undo/Redo با میانبرهای Ctrl+Z و Ctrl+Y و دکمه‌های رابط؛ نگهداری حداکثر ۵۰ وضعیت اخیر
- افزودن کلیپ به انتهای ترک مناسب؛ فایل‌های صوتی به A1 و سایر رسانه‌ها به V1
- تقسیم کلیپ انتخاب‌شده در محل نشانگر و حذف غیرمخرب از تایم‌لاین
- ذخیره پروژه با ساختار نسخه ۲ و سازگاری بارگذاری با پروژه‌های قدیمی

## نکات مهم پایداری و محدودیت‌ها
- فایل‌های ویدیو و صدا پس از تکمیل بررسی مشخصات با مدت واقعی به تایم‌لاین افزوده می‌شوند. اگر خواندن مدت ناموفق باشد، برای جلوگیری از چیدمان اشتباه، فایل صوتی/ویدیویی به تایم‌لاین افزوده نمی‌شود.
- تصاویر ثابت PNG/JPG فعلاً با طول پیش‌فرض پنج ثانیه وارد می‌شوند؛ مدت تصویر ثابت ذاتاً از فایل قابل استخراج نیست.
- برنامه ابتدا FFprobe را در PATH یا کنار FFmpeg پیدا می‌کند؛ در صورت نبودن آن، از خلاصه متنی FFmpeg به‌عنوان مسیر جایگزین استفاده می‌کند. هیچ فریم رسانه‌ای برای این بررسی Decode نمی‌شود و عملیات در پس‌زمینه انجام می‌شود.
- جابه‌جایی کلیپ در تایم‌لاین فقط اطلاعات تدوین را تغییر می‌دهد و فایل اصلی را دست‌کاری نمی‌کند.
- ذخیره پروژه ابتدا در فایل موقت انجام می‌شود و سپس جایگزینی اتمیک صورت می‌گیرد تا احتمال ناقص‌شدن فایل پروژه در زمان ذخیره کاهش یابد.
- پروژه پیشین تا وقتی فایل جدید با موفقیت خوانده و اعتبارسنجی نشده، در حافظه جایگزین نمی‌شود.
- پخش رسانه به کدک‌ها و backend موجود در ویندوز/Qt وابسته است؛ پشتیبانی یکسان از همه فرمت‌ها هنوز تضمین نشده است.
- ساخت Proxy در این نسخه با دکمه «ساخت Proxy سبک» و به‌صورت دستی آغاز می‌شود؛ پردازش در یک صف پس‌زمینه انجام می‌شود. Cache با تغییر اندازه/زمان ویرایش فایل اصلی یا نسخه تنظیمات Proxy، کلید تازه می‌گیرد. فایل اصلی برای خروجی نهایی حفظ می‌شود.
- شکل موج فقط برای کلیپ‌های صوتی روی ترک‌های A1 تا A4 ترسیم می‌شود؛ استخراج در صف تک‌وظیفه‌ای پس‌زمینه انجام می‌شود تا فشار CPU محدود بماند. در صورت نبود FFmpeg یا خطای فایل، کلیپ و فایل اصلی بدون شکل موج قابل استفاده باقی می‌مانند.
- Trim و Snap و Undo/Redo در این مرحله پیاده‌سازی شده‌اند؛ با این حال رابط دسکتاپ هنوز باید روی رایانه مقصد آزمایش شود و امکانات حرفه‌ای‌تر مانند ripple trim، slip/slide، انتخاب چندگانه و undo سراسری عملیات رسانه در مراحل بعدی می‌آیند.
- طراحی با اولویت 1080p، 30fps و مصرف پایین منابع انجام می‌شود؛ تدوین 4K هدف این نسخه نیست.

## نیازمندی‌ها
- Windows 10/11 64-bit
- Python 3.11 یا جدیدتر
- گردش‌کار هدف: 1080p و 30fps

## نصب و اجرا
فعلاً تا تکمیل چند مرحله و بررسی بیشتر، نیازی به نصب یا دانلود برای کاربر نیست. برای توسعه‌دهندگان، از ریشه مخزن:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r desktop_app\requirements.txt
python desktop_app\main.py
```

## تست مدل
تست‌های واحد مدل مستقل از رابط گرافیکی هستند. اجرای آن‌ها از ریشه مخزن:

```powershell
python -m unittest discover -s desktop_app -p "test_*.py"
```

توجه: وجود فایل تست به معنی اجرای موفق تست‌ها نیست؛ تست‌ها باید در محیط واقعی اجرا شوند. رابط PySide6 نیز هنوز روی رایانه مقصد کاربر آزمایش نشده است.

## مسیر توسعه
1. تست و تثبیت تایم‌لاین گرافیکی و هماهنگی نشانگر با پیش‌نمایش
2. تکمیل و آزمون خواندن مشخصات رسانه و نمایش waveform سبک
3. انتخاب چندگانه، ripple/slip/slide، undo سراسری و autosave
4. Proxy کم‌حجم و صف خروجی FFmpeg با H.264/1080p
5. ابزارهای صدا، رنگ، متن، ترنزیشن و compositing مرحله‌ای
