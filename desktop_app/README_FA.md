# ZENITH Desktop — پایه نسخه ویندوز

این پوشه آغاز نسخه دسکتاپ مستقل ZENITH است. نسخه آنلاین فعلی حذف یا جایگزین نشده است.

## قابلیت‌های پیاده‌سازی‌شده
- رابط دسکتاپ با PySide6 و ظاهر مشکی و طلایی
- ورود فایل‌های ویدیویی، صوتی و تصویری
- پیش‌نمایش رسانه با QMediaPlayer و QVideoWidget
- کنترل پخش، مکث، توقف و جابه‌جایی روی نوار زمان
- نمایش زمان فعلی و مدت رسانه
- افزودن و حذف آیتم‌ها از فهرست تایم‌لاین اولیه
- ذخیره و بازکردن پروژه با پسوند `.znproj`

> این نسخه هنوز تدوینگر کامل نیست. تایم‌لاین فعلی فقط فهرست کلیپ‌هاست و هنوز زمان‌بندی واقعی، چند ترک عملیاتی، برش/Trim و رندر نهایی پیاده‌سازی نشده‌اند. پخش فایل‌ها به پشتیبانی کدک‌های موجود در Qt/سیستم وابسته است.

## نیازمندی‌ها
- Windows 10/11 64-bit
- Python 3.11 یا جدیدتر
- گردش‌کار هدف: 1080p و 30fps؛ طراحی Proxy-first در مراحل بعد

## نصب و اجرا
در PowerShell، از ریشه مخزن:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r desktop_app\requirements.txt
python desktop_app\main.py
```

## مسیر توسعه
1. تکمیل پیش‌نمایش و پایداری پخش رسانه
2. تایم‌لاین زمان‌محور با ترک‌های V1/V2/A1/A2
3. برش، جابه‌جایی، Trim و Snap
4. پردازش FFmpeg و خروجی H.264 1080p
5. ابزارهای صدا، رنگ، متن، ترنزیشن و Proxy
